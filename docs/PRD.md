# PRD - 남문교회 홈페이지 리뉴얼

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 남문교회 홈페이지 리뉴얼 |
| 교회명 | 남문교회 (대한예수교장로회) |
| 위치 | 서울 금천구 독산동 |
| 담임목사 | 이건희 목사 |
| 목적 | XpressEngine 기반 노후화된 홈페이지를 현대적인 웹사이트로 개선 |
| 대상 사용자 | 교인 (전 연령대) 및 목회자 |

## 2. 기존 사이트 분석

### 현재 기술 스택
- CMS: XpressEngine (XE) - 2015년경 구축 추정
- 반응형: 미지원 (viewport 1024px 고정)
- SSL: 자체 서명 인증서 (보안 경고 발생)
- jQuery 기반, 레거시 IE 호환 코드 포함

### 현재 메뉴 구조
```
홈
├── 교회 소개
│   ├── 인사말/비전
│   ├── 교회 연혁
│   ├── 예배 & 훈련 안내
│   ├── 교회 소개 영상
│   ├── 섬기는 사람들 (사역자, 장로)
│   ├── 교회 소식 (공지사항, 주보)
│   └── 오시는 길
├── 변화 공동체
│   ├── 설교 (주일오전, 오후세미나, 수요, 새벽, 특별, 3분메시지)
│   ├── 찬양 (찬양대, 찬양팀)
│   ├── 칼럼 (목회 칼럼, 한 주의 인사)
│   └── 성경 공부 (셀모임공과, 성경연구)
├── 영향력 공동체
│   ├── 새가족 소개
│   ├── 남문 미디어 (행사 동영상, 교회 앨범)
│   └── 선교 (기도편지)
└── 세움 공동체
    ├── 유치부
    ├── 초등부
    ├── 중고등부
    ├── 청년부
    └── 장년부
```

### 기존 사이트 문제점
- 반응형 미지원 (모바일 접근성 없음)
- SSL 인증서 만료/자체 서명 (보안 경고)
- 10년 이상 된 프레임워크 (XE)
- IE 호환 코드로 인한 불필요한 복잡성
- 느린 로딩 속도
- 구시대적 디자인

## 3. 리뉴얼 목표

### 핵심 목표
1. **모바일 퍼스트 반응형** - 전 연령대가 스마트폰으로 쉽게 접근
2. **간결한 메뉴 구조** - 기존 4뎁스 → 최대 2뎁스로 단순화
3. **빠른 로딩** - 정적 생성(SSG)으로 즉각 로딩
4. **쉬운 접근성** - 큰 텍스트, 명확한 버튼, 단순한 네비게이션
5. **유지보수 용이** - 콘텐츠 수정이 쉬운 구조

### 비기능 요구사항
- 다크모드: 미지원 (불필요)
- 다국어: 미지원 (한국어만)
- 로그인/회원가입: 제외 (불필요)
- SEO: 기본 메타태그 + 시맨틱 HTML

- 히어로 섹션: 교회 대표 이미지 + 환영 문구
- 예배 시간 안내 (간략)
- 최신 설교 영상 (YouTube 임베드 1개)
- 최신 공지사항 (2-3개)

## 6. 기술 스택

### 추천 스택

| 카테고리 | 기술 | 선정 이유 |
|----------|------|-----------|
| 프레임워크 | **Next.js 15 (App Router)** | SSG로 빠른 로딩, 검색엔진 최적화, 이미지 최적화 내장 |
| 언어 | **TypeScript** | 타입 안전성, 유지보수성 |
| 스타일 | **Tailwind CSS** | 빠른 개발, 반응형 유틸리티, 일관된 디자인 |
| 배포 | **Vercel** | Next.js 최적 배포 환경, 무료 티어 충분 |
| 콘텐츠 관리 | **MDX (마크다운)** | 파일 기반으로 단순, DB 불필요, Git으로 버전 관리 |
| 지도 | **카카오맵 API** | 국내 서비스에 적합 |
| 영상 | **YouTube 임베드** | 기존 유튜브 채널 활용, 서버 부담 없음 |
| 아이콘 | **Lucide React** | 경량, 일관된 아이콘셋 |

### 왜 이 스택인가?

**DB/CMS를 쓰지 않는 이유:**
- 교회 사이트의 콘텐츠 변경 빈도가 낮음
- MDX 파일로 콘텐츠를 관리하면 DB 운영비 0원
- Git으로 모든 변경 이력 추적 가능
- 빌드 시 정적 HTML 생성 → 로딩 속도 극대화

**Next.js를 선택한 이유:**
- React 생태계의 표준 프레임워크
- SSG(정적 생성) + ISR(증분 정적 재생성) 지원
- 이미지 최적화 (`next/image`) 내장
- Vercel 무료 배포와 완벽 호환

## 7. 디자인 가이드라인

### 컬러 팔레트
| 용도 | 컬러 | 코드 |
|------|------|------|
| Primary | 네이비 블루 | `#1E3A5F` |
| Primary Light | 라이트 블루 | `#4A90D9` |
| Accent | 골드 | `#C8A951` |
| Background | 화이트 | `#FFFFFF` |
| Surface | 라이트 그레이 | `#F8F9FA` |
| Text Primary | 다크 그레이 | `#1A1A1A` |
| Text Secondary | 미디엄 그레이 | `#6B7280` |

> 교회의 신뢰감과 품격을 나타내는 네이비 + 골드 조합

### 타이포그래피
- 본문: Pretendard (가독성 우수한 한글 웹폰트)
- 크기: 본문 16px 이상 (노년층 가독성 고려)
- 행간: 1.7 이상

### 접근성
- 최소 터치 영역: 44px × 44px
- 충분한 색상 대비 (WCAG AA 기준)
- 명확한 포커스 표시
- 시맨틱 HTML 구조
