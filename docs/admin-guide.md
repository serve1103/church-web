## 1. Studio 접속하기

### 접속 방법

1. 컴퓨터(PC)의 웹 브라우저(크롬 권장)를 엽니다.
2. 주소창에 `https://nammoon.or.kr/studio` 를 입력합니다.
3. 처음 접속하시면 로그인 화면이 나타납니다. Google 계정으로 로그인하시면 됩니다.
4. 로그인 후 왼쪽에 메뉴 목록이 나타나면 정상적으로 접속된 것입니다.

### 화면 구성

Studio에 접속하면 상단에 세 가지 탭이 있습니다.

- **콘텐츠**: 설교, 공지사항, 주보, 앨범, 기도편지 등을 관리하는 곳입니다.
- **미리보기**: 수정한 내용이 실제 홈페이지에서 어떻게 보이는지 미리 확인할 수 있습니다.
- **미디어**: 업로드한 이미지와 파일을 모아서 관리할 수 있습니다.

왼쪽 목록에는 다음 항목들이 있습니다.

| 메뉴 | 설명 |
|------|------|
| 설교 | 설교 영상 등록/관리 |
| 공지사항 | 교회 공지 작성/관리 |
| 주보 | 주보 파일 업로드/관리 |
| 교회앨범 | 행사 사진 등록/관리 |
| 기도편지 | 선교 기도편지 작성/관리 |
| 관리 | 사이트 설정, 사역자 정보 수정 |

## 2. 설교 등록하기

새로운 설교를 등록하는 방법입니다. 유튜브에 업로드된 설교 영상의 링크만 복사해서 붙여넣으시면 됩니다.

### 유튜브 링크 복사하기

1. 유튜브에서 해당 설교 영상을 엽니다.
2. 영상 아래의 **"공유"** 버튼을 누릅니다.
3. **"복사"** 버튼을 눌러 링크를 복사합니다.
   - 복사된 링크는 `https://youtu.be/...` 형태입니다.
   - 또는 브라우저 주소창의 주소(`https://www.youtube.com/watch?v=...`)를 직접 복사하셔도 됩니다.

### Studio에서 설교 등록하기

1. 왼쪽 메뉴에서 **"설교"** 를 클릭합니다.
2. 오른쪽 상단의 **연필 아이콘(새 문서 만들기)** 을 클릭합니다.
3. 아래 항목들을 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 설교 제목 | 설교 제목을 입력합니다 | 필수 |
| 설교 날짜 | 설교가 진행된 날짜를 선택합니다 | 필수 |
| 예배 분류 | 주일오전, 수요예배 등 해당하는 예배를 선택합니다 | 필수 |
| 설교자 | 설교자 이름을 입력합니다 (예: 김목사) | 선택 |
| 성경본문 | 성경 구절을 입력합니다 (예: 요한복음 3:16-18) | 선택 |
| 유튜브 링크 | 복사한 유튜브 링크를 붙여넣습니다 | 필수 |
| 썸네일 이미지 | 비워두시면 유튜브 썸네일이 자동으로 사용됩니다 | 선택 |
| 설교 요약 | 설교 내용을 간단히 요약합니다 | 선택 |

4. 모든 입력이 끝나면 오른쪽 하단의 **"게시"** 버튼을 누릅니다.
5. 잠시 후 홈페이지에 설교가 표시됩니다.

### 설교 수정하기

1. **"설교"** 목록에서 수정할 설교를 클릭합니다.
2. 원하는 항목을 수정합니다.
3. **"게시"** 버튼을 눌러 저장합니다.

### 설교 삭제하기

1. 삭제할 설교를 클릭하여 엽니다.
2. 오른쪽 상단의 **점 세 개 메뉴(...)** 를 클릭합니다.
3. **"삭제"** 를 선택합니다.
4. 확인 메시지가 나타나면 **"삭제"** 를 한 번 더 클릭합니다.

## 3. 공지사항 관리하기

### 새 공지사항 작성하기

1. 왼쪽 메뉴에서 **"공지사항"** 을 클릭합니다.
2. 오른쪽 상단의 **연필 아이콘(새 문서 만들기)** 을 클릭합니다.
3. 아래 항목들을 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 공지 제목 | 공지 제목을 입력합니다 | 필수 |
| 분류 | "공지" 또는 "행사" 중 선택합니다 | 선택 (기본: 공지) |
| 공지 내용 | 본문을 작성합니다 | 필수 |
| 첨부파일 | 관련 파일을 첨부할 수 있습니다 | 선택 |
| 게시일 | 자동으로 현재 날짜가 입력됩니다 | 필수 |
| 상단 고정 | 켜면 공지 목록 최상단에 고정됩니다 | 선택 |

4. **"게시"** 버튼을 눌러 저장합니다.

### 공지 내용 작성 도움말

공지 내용 편집기에서는 다음 기능을 사용할 수 있습니다.

- **굵게**: 텍스트를 선택한 후 **B** 버튼을 누르면 굵게 표시됩니다.
- **기울임**: 텍스트를 선택한 후 **I** 버튼을 누르면 기울임체로 표시됩니다.
- **목록**: 번호 목록이나 점 목록을 만들 수 있습니다.
- **링크**: 텍스트를 선택하고 링크 버튼을 눌러 웹 주소를 연결할 수 있습니다.
- **이미지**: "+" 버튼을 눌러 본문 중간에 이미지를 삽입할 수 있습니다.

### 중요 공지 상단 고정하기

특별히 중요한 공지는 목록 최상단에 고정할 수 있습니다.

1. 해당 공지를 엽니다.
2. **"상단 고정"** 스위치를 켭니다.
3. **"게시"** 버튼을 누릅니다.
4. 홈페이지 공지 목록에서 "중요" 표시와 함께 맨 위에 나타납니다.

### 첨부파일 추가하기

1. 공지 작성 화면에서 **"첨부파일"** 항목의 **"추가"** 버튼을 클릭합니다.
2. 파일을 선택하여 업로드합니다.
3. 필요하면 "파일 설명"을 입력합니다 (예: "행사 안내문").
4. 여러 개의 파일을 추가할 수 있습니다.

### 공지사항 수정하기

1. 공지사항 목록에서 수정할 공지를 클릭합니다.
2. 원하는 내용을 수정합니다.
3. **"게시"** 버튼을 눌러 저장합니다.

### 공지사항 삭제하기

1. 삭제할 공지를 클릭하여 엽니다.
2. 오른쪽 상단의 **점 세 개 메뉴(...)** 를 클릭합니다.
3. **"삭제"** 를 선택하고, 확인 메시지에서 다시 **"삭제"** 를 클릭합니다.

## 4. 주보 업로드하기

매주 주보를 PDF 파일로 업로드할 수 있습니다.

### 새 주보 등록하기

1. 왼쪽 메뉴에서 **"주보"** 를 클릭합니다.
2. 오른쪽 상단의 **연필 아이콘** 을 클릭합니다.
3. 아래 항목들을 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 주보 제목 | 예: "2026년 2월 22일 주보" | 필수 |
| 주보 날짜 | 해당 주일 날짜를 선택합니다 | 필수 |
| 주보 파일 | PDF 파일을 업로드합니다 (10MB 이내) | 필수 |
| 표지 이미지 | 주보 표지 이미지를 등록하면 목록에서 미리보기가 됩니다 | 선택 |

4. **"게시"** 버튼을 누릅니다.

### 주보 파일 업로드 방법

1. **"주보 파일"** 항목에서 **"업로드"** 버튼을 클릭합니다.
2. 컴퓨터에서 PDF 파일을 선택합니다.
3. 파일이 업로드되면 파일 이름이 표시됩니다.
4. 파일을 교체하려면 기존 파일 옆의 **"지우기"** 버튼을 누른 후 새 파일을 업로드하시면 됩니다.

### 표지 이미지 등록 (권장)

표지 이미지를 등록하면 홈페이지 주보 목록에서 미리보기 이미지가 표시되어 보기 좋습니다.

1. 주보 PDF 첫 페이지를 캡처하거나 별도 이미지를 준비합니다.
2. **"표지 이미지"** 항목에서 이미지를 업로드합니다.

## 5. 교회앨범 사진 올리기

교회 행사나 예배 사진을 앨범으로 관리할 수 있습니다.

### 새 앨범 만들기

1. 왼쪽 메뉴에서 **"교회앨범"** 을 클릭합니다.
2. 오른쪽 상단의 **연필 아이콘** 을 클릭합니다.
3. 아래 항목들을 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 앨범 제목 | 예: "2026년 부활절 예배" | 필수 |
| 촬영 날짜 | 행사가 진행된 날짜를 선택합니다 | 필수 |
| 앨범 설명 | 앨범에 대한 간단한 설명입니다 | 선택 |
| 사진 목록 | 사진을 업로드합니다 (최소 1장) | 필수 |

4. **"게시"** 버튼을 누릅니다.

### 사진 업로드 방법

1. **"사진 목록"** 항목에서 **"추가"** 버튼을 클릭합니다.
2. **"업로드"** 를 선택하여 컴퓨터에서 사진을 선택합니다.
3. 한 번에 여러 장의 사진을 선택할 수 있습니다.
4. 업로드된 사진을 드래그하여 순서를 변경할 수 있습니다.
5. 각 사진을 클릭하면 "사진 설명"을 입력할 수 있습니다 (선택사항).

### 사진 추가/삭제하기

- **사진 추가**: 기존 앨범을 열고 사진 목록에서 **"추가"** 를 눌러 새 사진을 추가합니다.
- **사진 삭제**: 삭제할 사진 위에 마우스를 올리면 나타나는 **휴지통 아이콘** 을 클릭합니다.
- 수정 후 반드시 **"게시"** 를 눌러주세요.

## 6. 기도편지 작성하기

선교 기도편지를 작성하여 홈페이지에 게시할 수 있습니다.

### 새 기도편지 작성하기

1. 왼쪽 메뉴에서 **"기도편지"** 를 클릭합니다.
2. 오른쪽 상단의 **연필 아이콘** 을 클릭합니다.
3. 아래 항목들을 입력합니다.

| 항목 | 설명 | 필수 여부 |
|------|------|-----------|
| 제목 | 기도편지 제목을 입력합니다 | 필수 |
| 기도편지 내용 | 본문을 작성합니다 | 필수 |
| 첨부 사진 | 관련 사진을 첨부할 수 있습니다 | 선택 |
| 게시일 | 자동으로 현재 날짜가 입력됩니다 | 필수 |

4. **"게시"** 버튼을 누릅니다.

## 7. 사이트 설정 변경하기

홈페이지에 표시되는 교회 기본 정보를 수정할 수 있습니다.

### 사이트 설정으로 이동하기

1. 왼쪽 메뉴에서 **"관리"** 를 클릭합니다.
2. **"사이트 설정"** 을 클릭합니다.

### 변경할 수 있는 항목

| 항목 | 설명 |
|------|------|
| 교회 이름 | 홈페이지 헤더와 각종 위치에 표시되는 교회 이름 |
| 교회 로고 | 헤더에 표시되는 로고 이미지 (투명 배경 PNG 권장) |
| 주소 | 교회 주소 |
| 전화번호 | 교회 전화번호 |

수정 후 **"게시"** 버튼을 눌러 저장합니다.

### 사역자 정보 수정하기

1. **"관리"** > **"사역자"** 를 클릭합니다.
2. 수정할 사역자를 선택하거나, 새로 추가할 수 있습니다.
3. 이름, 직분, 사진, 소개글, 표시 순서를 입력합니다.
4. **"게시"** 를 눌러 저장합니다.

## 8. 미디어 라이브러리 사용법

미디어 라이브러리는 업로드된 모든 이미지와 파일을 모아서 관리하는 곳입니다.

### 미디어 라이브러리 접속

상단 탭에서 **"미디어"** 를 클릭합니다.

### 주요 기능

- **이미지 찾기**: 검색창에 파일 이름을 입력하여 이미지를 찾을 수 있습니다.
- **이미지 업로드**: 상단의 **"업로드"** 버튼으로 이미지를 미리 올려놓을 수 있습니다.
- **태그 관리**: 이미지에 태그를 붙여서 분류할 수 있습니다 (예: "설교", "행사" 등).
- **사용 현황 확인**: 각 이미지가 어떤 문서에서 사용되고 있는지 확인할 수 있습니다.
- **삭제**: 더 이상 사용하지 않는 이미지를 삭제할 수 있습니다. 단, 다른 문서에서 사용 중인 이미지는 삭제하지 않는 것이 좋습니다.

### 활용 팁

- 설교, 공지, 앨범 등을 작성할 때 이미지를 직접 업로드하면 자동으로 미디어 라이브러리에 저장됩니다.
- 이미 업로드한 이미지를 다른 곳에서 재사용하려면, 이미지 필드에서 **"찾아보기"** 를 눌러 미디어 라이브러리에서 선택하실 수 있습니다.

## 9. 자주 묻는 질문

### "게시" 버튼을 눌렀는데 홈페이지에 바로 반영되지 않아요.

게시 후 보통 몇 초 이내에 반영됩니다. 브라우저에서 홈페이지를 새로고침(F5 또는 Ctrl+R) 해보세요. 간혹 1~2분 정도 걸릴 수 있습니다.

### 실수로 내용을 잘못 수정했어요. 되돌릴 수 있나요?

네, 가능합니다. 문서를 열면 오른쪽에 수정 이력이 표시됩니다. 이전 버전을 선택하여 되돌릴 수 있습니다. 오른쪽 상단의 **점 세 개 메뉴(...)** 에서 **"기록 찾아보기"** 를 클릭하시면 됩니다.

### 유튜브 링크를 어떻게 복사하나요?

1. 유튜브에서 해당 영상 페이지를 엽니다.
2. 영상 아래의 **"공유"** 버튼을 누릅니다.
3. **"복사"** 버튼을 누릅니다.
4. Studio 설교 등록 화면의 "유튜브 링크" 항목에 붙여넣기(Ctrl+V) 합니다.

### 이미지 크기 제한이 있나요?

특별한 크기 제한은 없지만, 너무 큰 파일은 업로드가 느릴 수 있습니다. 일반적으로 한 장당 5MB 이내를 권장합니다. 주보 PDF 파일은 10MB 이내를 권장합니다.

### 주보 표지 이미지는 꼭 등록해야 하나요?

필수는 아닙니다. 하지만 표지 이미지를 등록하면 주보 목록에서 미리보기 이미지가 표시되어 성도분들이 찾기 쉽습니다. 주보 PDF 첫 페이지를 캡처하여 등록하시면 좋습니다.

### 공지사항에 사진을 넣을 수 있나요?

네, 공지 내용 편집기에서 **"+" 버튼** 을 눌러 이미지를 삽입할 수 있습니다. 컴퓨터에서 이미지를 선택하여 업로드하시면 본문 중간에 사진이 들어갑니다.

### 설교 영상의 썸네일 이미지를 직접 지정해야 하나요?

아닙니다. 썸네일 이미지 항목을 비워두시면 유튜브에 등록된 썸네일이 자동으로 사용됩니다. 별도의 이미지를 사용하고 싶을 때만 등록하시면 됩니다.

### 미리보기는 어떻게 사용하나요?

1. 상단 탭에서 **"미리보기"** 를 클릭합니다.
2. 왼쪽에서 편집할 문서를 선택하면, 오른쪽에 실제 홈페이지 화면이 표시됩니다.
3. 오른쪽 미리보기 화면에서 수정하고 싶은 부분을 직접 클릭하면 해당 편집 화면으로 이동합니다.
4. 수정한 내용이 실시간으로 미리보기에 반영됩니다.
5. 수정이 완료되면 **"게시"** 를 눌러 저장합니다.

### Studio는 휴대폰에서도 사용할 수 있나요?

Studio는 컴퓨터(PC)에서 사용하시는 것을 권장합니다. 휴대폰이나 태블릿에서는 화면이 작아 사용이 불편할 수 있습니다.

### 로그인이 안 돼요.

Studio 접속 권한은 관리자가 등록한 Google 계정으로만 가능합니다. 로그인이 안 되시면 관리자에게 문의하여 접속 권한을 확인해주세요.
