## 공통 사항

### 네비게이션 브레이크포인트
- **모바일/태블릿** (< 1024px): 햄버거 메뉴 (`lg:hidden`)
- **데스크톱** (>= 1024px): 수평 네비게이션 바 (`hidden lg:block`)
- 768px 태블릿에서도 햄버거 메뉴가 표시된다. 태블릿 가로 모드(1024px)에서는 데스크톱 네비게이션이 나타난다.

### 공통 발견 사항
1. **Footer 링크 터치 영역**: Footer의 하위 메뉴 링크들이 `text-xs`(12px)이며, 행 높이가 좁아 터치 영역이 44px 미만이다. 모바일에서 정확한 탭이 어려울 수 있다.
2. **Footer 레이아웃**: `md:grid-cols-2` 브레이크포인트를 사용하여 768px부터 2컬럼으로 전환된다. 모바일에서는 1컬럼 스택으로 적절하게 표시된다.

### 1. `/` (홈)

#### 스크린샷
- 모바일: `docs/screenshots/home-mobile-375.png`
- 태블릿: `docs/screenshots/home-tablet-768.png`
- 데스크톱: `docs/screenshots/home-desktop-1280.png`

#### 모바일 (375px)
- **레이아웃**: 양호. 모든 섹션이 세로 스택으로 올바르게 표시된다.
- **히어로 블록**: 전체 너비로 잘 렌더링된다. CTA 버튼 터치 영역 적절.
- **퀵링크 블록**: 1컬럼 세로 스택으로 표시. 아이콘+텍스트 구성이 적절하다.
- **최신 설교**: featured 설교가 전체 너비로, 나머지 3개는 리스트로 표시. 썸네일이 `142px` 고정 너비로 적절.
- **공지사항**: 제목이 `truncate`로 처리되어 잘림 없이 표시된다.
- **예배 안내**: 카드가 1컬럼으로 세로 스택. 카드 간격과 패딩이 적절.

#### 태블릿 (768px)
- **레이아웃**: 양호.
- **퀵링크 블록**: `sm:grid-cols-2`로 2컬럼 그리드. 적절.
- **최신 설교**: featured 설교와 리스트가 1컬럼으로 스택 (lg 미만). 적절한 전환.
- **예배 안내**: `sm:grid-cols-2`로 2컬럼 그리드. 5개 서비스 중 마지막 1개가 단독 행.
- **경미한 이슈**: 예배 안내 섹션에서 5개 카드가 2컬럼 그리드에 배치되어 마지막 카드가 왼쪽 정렬로 단독 배치된다. 시각적으로 약간 불균형.

#### 데스크톱 (1280px)
- **레이아웃**: 양호. 데스크톱 네비게이션 정상 표시.
- **퀵링크 블록**: `lg:grid-cols-4`로 4컬럼. 균형 잡힌 배치.
- **최신 설교**: `lg:grid-cols-[1.2fr_1fr]` 2컬럼 레이아웃으로 featured + 리스트가 나란히 표시.
- **예배 안내**: `lg:grid-cols-3`으로 3컬럼. 5개 카드 중 2개가 마지막 행.
- **공지사항**: `max-w-3xl`로 적절한 읽기 너비.

#### 발견된 문제점
| # | 심각도 | 설명 |
|---|--------|------|
| H-1 | 낮음 | 예배 안내 섹션: 5개 카드의 홀수 배치로 태블릿(2컬럼)과 데스크톱(3컬럼) 모두 마지막 행이 비대칭 |

#### 수정 제안
- **H-1**: 마지막 카드에 `sm:col-span-2 lg:col-span-1` 등으로 중앙 정렬하거나, 데이터 레벨에서 카드 수를 3 또는 6의 배수로 맞추는 것을 고려.

### 2. `/about` (교회소개)

#### 스크린샷
- 모바일: `docs/screenshots/about-mobile-375.png`
- 태블릿: `docs/screenshots/about-tablet-768.png`
- 데스크톱: `docs/screenshots/about-desktop-1280.png`

#### 모바일 (375px)
- **페이지 헤더**: 내부 탭 네비게이션 (예배안내, 섬기는 사람들, 연혁, 오시는 길) 이 `overflow-x-auto`로 가로 스크롤 가능. 적절.
- **인사말**: 텍스트가 자연스럽게 줄바꿈. 적절한 패딩(px-4).
- **예배 안내**: 1컬럼 세로 스택. 각 서비스 카드에 이름, 시간, 장소가 표시.
- **섬기는 사람들**: 프로필 사진과 이름이 1컬럼으로 세로 스택. 적절.
- **교회 연혁**: 타임라인이 좌측 정렬 세로로 표시.
- **오시는 길**: 지도와 연락처가 세로 스택.
- **경미한 이슈**: 예배 안내 섹션에서 "초등부 예배", "중고등부 예배", "청년부 예배" 등 9개 서비스가 모두 1컬럼으로 나열되어 스크롤이 매우 길어진다.

#### 태블릿 (768px)
- **예배 안내**: `sm:grid-cols-2`로 2컬럼 그리드. 9개 서비스가 5행으로 배치.
- **섬기는 사람들**: 2컬럼 그리드. 적절한 배치.
- **교회 연혁**: 타임라인 적절히 표시.
- **오시는 길**: 지도와 연락처가 적절히 배치.

#### 데스크톱 (1280px)
- **예배 안내**: `lg:grid-cols-3`으로 3컬럼. 9개 서비스가 3행에 깔끔하게 배치.
- **섬기는 사람들**: 4컬럼 그리드. 적절.
- **모든 섹션**: 적절한 여백과 max-width 적용.

#### 발견된 문제점
| # | 심각도 | 설명 |
|---|--------|------|
| A-1 | 낮음 | 모바일에서 예배 안내 서비스 카드 9개가 1컬럼으로 긴 스크롤 유발 |
| A-2 | 낮음 | 교회 연혁 타임라인의 연도/내용 텍스트가 모바일에서 좁은 공간에 배치됨 |

#### 수정 제안
- **A-1**: 모바일에서도 `grid-cols-2`로 변경하거나, 아코디언 형태로 접을 수 있는 UI 고려. 또는 서비스를 주일/주중으로 그룹핑.
- **A-2**: 현재 구현은 기능적으로 문제 없으나, 연도 라벨의 너비가 좁으면 줄바꿈이 발생할 수 있으므로 확인 필요.

#### 발견된 문제점
| # | 심각도 | 설명 |
|---|--------|------|
| S-1 | 매우 낮음 | 카테고리 필터 탭의 높이가 약 36px로 44px 최소 터치 영역 기준에 미달 (py-2 = 8px * 2 + text-sm 20px = 약 36px) |

#### 수정 제안
- **S-1**: `py-2`를 `py-2.5` 또는 `py-3`으로 변경하여 터치 영역을 44px 이상으로 확대 권장.

## 긍정적 사항

1. **수평 오버플로우 없음**: 모든 페이지, 모든 뷰포트에서 가로 스크롤바가 발생하지 않는다.
2. **모바일-퍼스트 설계**: Tailwind의 `sm:`, `md:`, `lg:` 브레이크포인트를 적절하게 활용하고 있다.
3. **이미지 반응형**: `next/image`의 `fill` + `object-cover` + `sizes` 속성을 올바르게 사용하여 모든 뷰포트에서 이미지가 깨지지 않는다.
4. **텍스트 오버플로우 처리**: `truncate`, `line-clamp-2` 등으로 긴 텍스트가 적절히 처리된다.
5. **네비게이션 전환**: lg 브레이크포인트(1024px)에서 모바일 햄버거 <-> 데스크톱 네비게이션 전환이 자연스럽다.
6. **빈 상태 처리**: 데이터가 없는 경우 적절한 안내 메시지가 중앙에 표시된다.
7. **max-width 제한**: `max-w-6xl`(1152px)로 데스크톱에서 콘텐츠가 지나치게 넓어지지 않는다.
8. **그리드 반응형 전환**: 1컬럼 -> 2컬럼 -> 3/4컬럼 전환이 자연스럽다.
